# Ancient Map Challenge

Ho appena caricato il file ZIP del mio progetto e ti allegato l'immagine della cartina storica. 

Voglio sostituire completamente la vecchia mappa geometrica a blocchi con questa immagine esatta. 

Modifica il codice HTML e CSS affinché l'immagine sia lo sfondo principale della mappa, e posiziona sopra dei marker interattivi con coordinate CSS percentuali nei punti chiave (Hispania, Italia, Grecia, Nord Africa, ecc.). Mantieni intatta la logica del timer a 5 minuti, delle domande e del punteggio.
