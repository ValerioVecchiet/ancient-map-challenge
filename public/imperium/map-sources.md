# Modern political map

Country geometry: Natural Earth, Admin 0 Countries, 1:10 million, public domain.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson

The map uses Lambert azimuthal equal-area projection centered on Europe. It is clipped to 26°W–46°E, 24°N–72°N; countries extending outside this viewport are shown partially. Overseas territories are excluded by this viewport. The geographic paths remain real polygons, including microstates, with no enlarged dots or point symbols.

Natural Earth's de facto boundary conventions are used. Kosovo is represented separately. Capital names use common Italian geography conventions; Israel's capital is given as Jerusalem (international status disputed). Boundary depiction is not a statement on sovereignty.
